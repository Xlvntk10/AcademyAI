# Academy AI V3 — PWA, mobile и offline

5 ноября 2026 года. Работа выполнена в существующем репозитории, в ветке `feature/academy-ai-v2`. Начальное состояние Git было чистым, исходный коммит этой сессии — `4c98c18`.

## Реализованные функции

### Локальная библиотека

- Кнопка «Скачать урок» на странице теории и в разделе «Локальная библиотека».
- Хранение теории, примеров, упражнений, версии и отпечатка урока в IndexedDB.
- Чтение сохранённой теории и выполнение choice/text-заданий английского и Python при недоступном API.
- Автосохранение вводимых ответов в IndexedDB, восстановление черновика и защита от перезаписи устаревшей вкладкой.
- Фиксация завершённой попытки в устойчивой очереди. Она сохраняется при перезагрузке приложения.
- Отправка при открытии, восстановлении сети, возврате на вкладку, раз в минуту на видимой странице и по кнопке.
- Состояния черновика, очереди, подтверждённого результата и конфликта. После подтверждения доступны серверные объяснения.
- Экспорт локальных попыток в JSON и запрос постоянного хранилища по действию пользователя.

Для офлайн-практики выбран режим отложенной проверки. До соединения ученик видит сохранённые ответы и очередь. Правильность и баллы становятся доступны после ответа сервера. Такая попытка использует снимок скачанной версии урока. Обновление библиотеки сохраняет этот снимок внутри попытки.

### Серверный обмен

`GET /api/offline/lessons/{slug}` выдаёт учебный пакет. `POST /api/offline/attempts` принимает UUID, идентификатор базы, версию, SHA-256 отпечаток, время и ответы. Проверка и запись всех упражнений проходят в одной транзакции SQLite.

Принятый результат сохраняется как квитанция. Повтор того же запроса, включая одновременные запросы, возвращает ту же квитанцию. Другие ответы под прежним UUID дают HTTP 409. Устаревшая версия, другая база и закрытые предпосылками темы также дают понятный конфликт. Локальная копия остаётся доступной для чтения и экспорта.

XP использует существующее правило лучшего завершённого результата урока. Даже новое повторное прохождение с другим UUID повышает XP только при улучшении результата. Запущенное ранее онлайн-прохождение сохраняет собственную историю отдельно от новой офлайн-попытки.

Клиентское время хранится в квитанции. Для streak и общей активности используется время приёма сервером. При отправке занятий за несколько офлайн-дней они отражаются в активности в день приёма. Это выбранное правило текущей версии.

### PWA

- Дополнен манифест, добавлены shortcuts, параметры iPhone и монохромная векторная иконка.
- Проверены существующие PNG 192/512, maskable 512 и Apple touch icon 180×180.
- Service Worker кеширует файлы сборки и отдаёт согласованную оболочку одного выпуска.
- Ответы API получают `Cache-Control: no-store`. Учебные данные сохраняются явно через IndexedDB.
- Новая версия ожидает действия пользователя. Уведомление ведёт в настройки, где доступна кнопка обновления. При наличии других вкладок предлагается сначала закрыть их.
- Сохраняется предыдущий статический кеш для открытых страниц. Установка новой оболочки сама по себе не перезагружает текущую практику.
- Service Worker сообщает интерфейсу, что все файлы оболочки присутствуют в кеше.
- Добавлен вход в скачанные уроки при ошибке API и доступ к библиотеке при прямом открытии `/#offline`.
- В Vite добавлена опциональная поддержка собственного HTTPS-сертификата через переменные окружения.

### Напоминания и виджеты

Настройки позволяют выбрать дни недели и время. Последние полученные настройки напоминаний сохраняются локально. Запрос разрешения на системные уведомления происходит только по нажатию кнопки. Проверка времени выполняется на открытой видимой странице.

`GET /api/widgets/v1/summary` возвращает streak, сегодняшние задачи, охват английского и Python, а также обратный отсчёт до выбранной даты магистратуры. Дата задаётся в настройках. Пока она не выбрана, API возвращает `null` вместо числа оставшихся дней.

### Что удалось проверить браузером

На отдельном origin `http://127.0.0.1:4273` был скачан урок Everyday facts. При остановленных тестовых серверах заполнены шесть упражнений. После восстановления соединения черновик восстановился. При остановленном API завершённая попытка осталась в очереди. После возврата API она была принята с результатом 60/60. Общий XP тестовой копии изменился с 50 до 110, повторная отправка оставила 110. На ширине 390 px проверен экран результата в тёмной теме.

Холодное открытие оболочки при остановленных frontend и backend во встроенном браузере дважды дало пустую страницу. Причина в доступной среде не установлена. Затем инструмент прекратил управление браузером, потому что не смог надёжно определить URL Windows. Установка PWA в обычном Chrome/Edge, холодный запуск на устройствах, обновление установленного приложения и обе темы на физических телефонах остаются непроверенными. Автоматические проверки Service Worker и сообщение о готовности кеша подтверждают программную часть, а завершение проверки на устройстве остаётся обязательным перед использованием в поездке.

## Установка на Windows

Открой два терминала PowerShell в VS Code. Если FastAPI уже запущен на 8000, используй существующий процесс после обновления кода.

Первый терминал запускает API.

```powershell
Set-Location 'C:\Users\user\OneDrive\Рабочий стол\applied-is-project-2026'
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Второй терминал собирает и запускает production frontend.

```powershell
Set-Location 'C:\Users\user\OneDrive\Рабочий стол\applied-is-project-2026\frontend'
npm.cmd run build
npm.cmd run preview
```

1. Открой `http://127.0.0.1:4173` в Edge или Chrome.
2. В настройках Academy AI нажми «Установить Academy AI», если браузер предоставил кнопку. Также доступен пункт установки в меню браузера.
3. Открой «Локальная библиотека» и дождись сообщения Service Worker о наличии оболочки в кеше.
4. Скачай урок, открой его теорию и начни практику на устройстве.
5. Проверь сохранение ответа, закрой и открой приложение. Для проверки полного автономного запуска останови оба терминала и повтори открытие.
6. Запусти серверы, отправь очередь и проверь результат. Повтори отправку и убедись, что XP сохранился.

Используй один и тот же адрес. `localhost`, `127.0.0.1`, другой порт и HTTPS имеют отдельные браузерные хранилища. При переходе на новый адрес сначала отправь очередь или скачай JSON-копию ответов.

Для разработки можно использовать `npm.cmd run dev`, открывая порт 5173. Регистрация Service Worker включена в production-сборке.

## Проверка на телефоне

Для обычной проверки интерфейса подключи телефон и компьютер к одной доверенной Wi-Fi сети. При запущенном API выполни во втором терминале следующее.

```powershell
Set-Location 'C:\Users\user\OneDrive\Рабочий стол\applied-is-project-2026\frontend'
npm.cmd run preview -- --host 0.0.0.0
```

Открой `http://<IPv4-компьютера>:4173`. API остаётся за Vite proxy. Для установки PWA и Service Worker телефону требуется доверенный HTTPS-origin. Саму мобильную установку нужно проверять отдельно на Android и iPhone.

Подготовлена возможность использовать сертификат с подходящим DNS-именем или IP в SAN, которому доверяют компьютер и телефон. Получение сертификата и настройка доверия требуют отдельного действия владельца. Если такие файлы уже подготовлены, запусти preview следующим образом.

```powershell
$env:ACADEMY_HTTPS_CERT = 'C:\AcademyTLS\academy.crt'
$env:ACADEMY_HTTPS_KEY = 'C:\AcademyTLS\academy.key'
npm.cmd run preview -- --host 0.0.0.0
```

Открой HTTPS-адрес, соответствующий сертификату. На iPhone используй Safari → «Поделиться» → «На экран Домой». На Android используй установку из меню Chrome. Затем проверь кеш, скачивание, авиарежим, перезапуск приложения и отправку очереди после возврата сети. Ключи сертификата храни вне Git. Для локального хранения внутри проекта зарезервирована игнорируемая папка `.local-tls/`.

Системные настройки сети, сертификаты и правила Windows Firewall в этой сессии не изменялись. Доступ к домашнему API пока предназначен для личной доверенной сети. Публичное размещение требует авторизации и защиты данных по отдельному плану.

## Ограничения текущего этапа

- Для окончательной проверки ответов и начисления XP требуется доступ к домашнему FastAPI.
- Очередь отправляется при открытом приложении. Доставка после полного закрытия зависит от следующего открытия.
- Напоминания работают в выбранную минуту на видимой странице. Закрытое приложение, сон устройства и экономия энергии ограничивают доставку.
- Офлайн-библиотека охватывает объективные уроки английского и Python. IELTS, календарь, общая статистика и словарь продолжают использовать свои существующие онлайн-сценарии.
- Очистка профиля браузера может удалить локальные данные. Запрос постоянного хранилища браузер вправе отклонить. JSON-экспорт предназначен для сохранения читаемой копии, автоматический импорт пока отсутствует.
- Конфликт версии требует сохранить ответы и пройти актуальную версию. Повтор исходной попытки полезен после возврата правильного сервера или отправки предпосылок.
- Авторизация, облачный журнал изменений, перенос между аккаунтами, Web Push и нативные виджеты входят в следующий этап.
- Одно предупреждение Starlette о поддержке `httpx` в TestClient сохраняется.
- Полная приёмка установленного PWA на Windows, iPhone и Android требует завершения ручных проверок, описанных выше.
